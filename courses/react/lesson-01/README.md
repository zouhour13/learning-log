# Lesson 1 — React Basics

## 📚 What I Learned

### 1. What is React?

React is an external JavaScript library that helps developers create websites and user interfaces more easily.

### 2. Loading React

I learned how to load the React external library into a project.

### 3. Setting Up React

I learned how to set up React and display content using `.render()`.

### 4. HTML and JavaScript Review

This lesson also reviewed important HTML and JavaScript fundamentals used when working with React.

### 5. JSX

JSX is an enhanced version of JavaScript that allows us to describe HTML-like elements directly in JavaScript code.

### 6. Creating Elements with JSX

I learned how to create UI elements directly using JSX.

### 7. Inserting Values into JSX

I learned how to insert JavaScript values dynamically inside JSX elements.

## 💻 Practice

I created a simple React profile interface using JSX and JavaScript variables.

The project displayed dynamic information such as:

* Name
* Role
* Skills
* Current learning topic

## 🧠 Key Takeaways

* React makes building user interfaces easier.
* JSX allows us to create UI elements using JavaScript syntax.
* JavaScript values can be inserted dynamically into JSX.
* React uses rendering to display UI elements on the webpage.
