# Technical Courses

> **Author:** zouhour13

This directory contains technical learning notes organized by subject. Each course has its own folder with focused Markdown files and reference material.

## Browse courses

- [Cybersecurity — English and French](https://github.com/zouhour13/learning-log/tree/main/courses/security) — security fundamentals, cryptography, network defense, application and API security, system hardening, incident response, resilience, and privacy.
- [Computer Networking](https://github.com/zouhour13/learning-log/tree/main/courses/networking) — networking fundamentals, OSI and TCP/IP models, IPv4 addressing, subnetting, protocols, routing, and network services.
- [Software Design, UML and System Design](https://github.com/zouhour13/learning-log/tree/main/courses/conception-logicielle-system-design) — requirements analysis, UML, software architecture, relational databases, scalability, APIs, resilience, observability, and testing.
- [Systèmes d’exploitation](https://github.com/zouhour13/learning-log/tree/main/courses/systemes-exploitation) — operating-system fundamentals, processes and threads, CPU scheduling, memory management and virtual memory, synchronization, deadlocks, Linux commands and administration, filesystems, and input/output.
