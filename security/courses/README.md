# Cybersecurity Courses

> **Author:** Zouhour Bellamine

A structured collection of self-learning notes on cybersecurity fundamentals, cryptography, network defense, application security, system administration, and resilience.

## Courses

- [01 — Security fundamentals](01-security-fundamentals.md): CIA triad, identity, authentication, authorization, access control, least privilege.
- [02 — Cryptography](02-cryptography.md): encryption, hashing, password storage, signatures, certificates, PKI, TLS.
- [03 — Network security](03-network-security.md): firewalls, IDS/IPS, VPNs, segmentation, common ports, network attacks.
- [04 — Threats and application security](04-threats-and-application-security.md): phishing, malware, ransomware, web and API vulnerabilities.
- [05 — Systems and security operations](05-systems-and-security-operations.md): Linux permissions, hardening, logs, SIEM, incident response.
- [06 — Resilience and governance](06-resilience-and-governance.md): backups, RPO/RTO, continuity, privacy, organizational controls.
- [Self-assessment](self-assessment.md): practice questions and explanations.

## Learning approach

1. Understand each concept and its purpose.
2. Compare concepts that are easy to confuse.
3. Connect threats to their impact and appropriate controls.
4. Test understanding with the self-assessment.

These notes are an independent technical learning resource. They are not a substitute for current standards, vendor documentation, or applicable legal requirements.
