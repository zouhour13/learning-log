## Core principles

- **Confidentiality:** prevent unauthorized disclosure.
- **Integrity:** prevent or detect unauthorized changes.
- **Availability:** keep systems usable by authorized users.
- **Least privilege:** grant only permissions necessary for a task.
- **Defense in depth:** combine complementary controls.
- **Secure by design:** include security throughout development and maintenance.
- **Verify explicitly:** do not trust identities only because they are on an internal network.
- **Recoverability:** backups matter only when restoration is possible and tested.

These notes are an independent technical learning reference, not a complete security standard or legal interpretation. Apply controls according to the system threat model, applicable regulations, and current vendor guidance.
