# Cybersecurity Fundamentals

A structured reference for core cybersecurity concepts, defensive controls, secure systems, and risk management.

- [Self-assessment](self-assessment.md): practice questions and explanations.

## Core principles
- Confidentiality: prevent unauthorized disclosure.
- Integrity: prevent or detect unauthorized changes.
- Availability: keep systems usable by authorized users.
- Least privilege: grant only permissions necessary for a task.
- Defense in depth: combine complementary controls.
- Secure by design: include security throughout development and maintenance.
- Verify explicitly: do not trust identities only because they are on an internal network.
- Recoverability: backups matter only when restoration is possible and tested.

## How to use these notes
1. Explain each concept in your own words.
2. Compare similar concepts and identify their differences.
3. For each threat, identify its objective, entry path, impact, and mitigations.
4. Test understanding with the self-assessment and revisit missed topics.

These notes are a technical learning reference, not a complete security standard or legal interpretation. Apply controls according to the system's threat model, applicable regulations, and current vendor guidance.
